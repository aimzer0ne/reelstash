Di laptop atau komputer, Instagram tidak menyediakan cara untuk menyimpan Reels: opsi **Unduh** hanya ada di aplikasi HP. Solusi mudahnya adalah menyalin alamat Reels dari browser, menempelkannya ke [pengunduh video Instagram](/id), lalu menyimpan MP4-nya. Cara ini berjalan di Windows, macOS, Linux, dan ChromeOS, di browser modern apa pun, dan musiknya tetap ada di dalam file.

## Langkah demi langkah

### 1. Salin link Reels

Buka Reels di **instagram.com**. Ada dua cara mendapatkan link-nya:

- **Dari bilah alamat.** Klik alamatnya, pilih, lalu salin. Link Reels berbentuk `instagram.com/reel/…` atau `instagram.com/reels/…`.
- **Dari menu.** Klik **titik tiga** pada Reels dan pilih **Salin tautan**.

Jika Anda sedang menggulir feed Reels, bilah alamat berubah setiap kali Reels baru muncul, jadi pastikan Reels yang Anda inginkan adalah yang sedang diputar sebelum menyalin.

### 2. Tempel ke pengunduh

Buka [reelsdl.net](/id) di tab baru. Klik kotaknya, tekan **Ctrl + V** (Windows, Linux, ChromeOS) atau **⌘ + V** (Mac), lalu tekan **Enter**.

### 3. Simpan MP4

Pratinjau Reels muncul dalam beberapa detik. Klik **Unduh video**. File tersimpan di folder Download.

## Ke mana file tersimpan

| Sistem | Lokasi bawaan | Cara cepat membukanya |
| --- | --- | --- |
| Windows | `Downloads` di folder pengguna | Tekan **Ctrl + J** di browser |
| macOS | `Unduhan` di folder utama | Klik tumpukan Unduhan di Dock |
| ChromeOS | *File → Download* | Klik baki unduhan di rak |
| Linux | `~/Downloads` | Tekan **Ctrl + J** di browser |

Ingin memilih folder setiap kali? Di Chrome atau Edge, buka *Setelan → Download* dan aktifkan **Tanyakan lokasi penyimpanan setiap file sebelum mendownload**. Di Safari ada di *Pengaturan → Umum → Lokasi unduhan file*.

## Apakah musik Reels tetap ada?

Ya. MP4 berisi trek audio yang sama dengan yang diputar di Instagram, baik itu lagu berlisensi, sulih suara, maupun suara asli. Ini berbeda dengan tombol Unduh di aplikasi HP, yang bisa menyimpan salinan tanpa suara jika Reels memakai lagu dari pustaka musik Instagram.

Jika file terasa tanpa suara di komputer:

- Pastikan volume sistem dan pemutar media tidak dibisukan.
- Buka file di pemutar lain. **VLC** bisa memutar hampir semua MP4.
- Pastikan Reels aslinya masih bersuara di Instagram.

Kalau hanya butuh musiknya, [pengunduh audio Reels](/id/audio) menyimpan link yang sama sebagai MP3. Lihat [cara mengambil audio dari Reels Instagram](/id/blog/extract-audio-from-instagram-reel-mp3).

## Cara lain, dan kenapa kurang baik

**Ekstensi browser.** Ekstensi menambahkan tombol unduh di instagram.com, dan itu memang praktis. Harganya adalah izin yang diminta: membaca dan mengubah data di situs yang Anda kunjungi, termasuk tab tempat Anda login ke Instagram. Ekstensi juga bisa berganti pemilik dan ditarik dari toko tanpa banyak pemberitahuan. Jika memakainya, periksa dulu izin dan ulasannya.

**Rekam layar.** Windows (Xbox Game Bar, **Win + G**) dan macOS (**⇧ + ⌘ + 5**) sama-sama bisa merekam layar. Antarmuka ikut terekam, kualitasnya bergantung pada layar Anda, dan di Mac perekam bawaan mungkin tidak menangkap suara komputer tanpa software tambahan.

**Alat pengembang.** Panduan lama menyuruh membuka inspector browser dan mencari file `.mp4` di tab Network. Sekarang Instagram menyajikan sebagian besar video dalam segmen audio dan video yang terpisah, sehingga hasilnya biasanya file tanpa suara atau tidak lengkap.

**Software desktop.** Program yang mengunduh dari Instagram memang ada, tetapi memasang software hanya untuk sesekali menyimpan Reels lebih berisiko dan merepotkan daripada membuka satu tab browser.

## Kirim Reels ke HP

Setelah MP4 ada di komputer, memindahkannya ke HP cepat saja:

- **Mac ke iPhone:** klik kanan file, pilih *Bagikan → AirDrop*. File langsung masuk ke Foto.
- **Windows atau Chromebook ke Android:** gunakan **Quick Share**, atau colokkan kabel USB dan seret file ke folder *Download* atau *DCIM* di HP.
- **Kombinasi apa pun:** unggah ke Google Drive, iCloud Drive, atau OneDrive, atau kirim ke diri sendiri lewat pesan.

Atau lewati komputer untuk langkah itu: pengunduh yang sama juga berjalan di browser HP. Versi HP dari panduan ini adalah [cara menyimpan Reels ke galeri dengan musik](/id/blog/save-instagram-reels-in-gallery-with-music).

## Yang tidak bisa diunduh

- **Akun privat.** Sedang login ke Instagram di browser yang sama tidak berpengaruh. Pengunduh tidak pernah melihat sesi Anda dan hanya bisa menjangkau postingan publik.
- **Reels yang dihapus.** Link ke Reels yang sudah dihapus tidak menghasilkan apa-apa.
- **Link yang salah.** Alamat profil (`instagram.com/namapengguna`) bukan Reels. Buka Reels-nya langsung dan salin lagi.
