노트북이나 데스크톱에서는 인스타그램에 릴스를 저장할 방법이 없습니다. **다운로드** 옵션은 휴대폰 앱에만 있습니다. 간단한 해결 방법은 브라우저에서 릴스 주소를 복사해 [인스타그램 동영상 다운로더](/ko)에 붙여넣고 MP4를 저장하는 것입니다. Windows, macOS, Linux, ChromeOS의 최신 브라우저라면 어디서든 작동하고 음악도 파일에 그대로 남습니다.

## 단계별 안내

### 1. 릴스 링크 복사

**instagram.com**에서 릴스를 엽니다. 링크를 얻는 방법은 두 가지입니다.

- **주소창에서.** 주소를 클릭해 선택하고 복사합니다. 릴스 링크는 `instagram.com/reel/…` 또는 `instagram.com/reels/…` 형태입니다.
- **메뉴에서.** 릴스의 **점 세 개**를 클릭하고 **링크 복사**를 선택합니다.

릴스 피드를 스크롤하는 중이라면 릴스가 바뀔 때마다 주소창도 바뀝니다. 복사하기 전에 원하는 릴스가 재생 중인지 확인하세요.

### 2. 다운로더에 붙여넣기

새 탭에서 [reelsdl.net](/ko)을 엽니다. 입력창을 클릭하고 **Ctrl + V**(Windows, Linux, ChromeOS) 또는 **⌘ + V**(Mac)를 누른 다음 **Enter**를 누릅니다.

### 3. MP4 저장

몇 초 안에 릴스 미리보기가 나타납니다. **동영상 다운로드**를 클릭하면 파일이 다운로드 폴더에 저장됩니다.

## 파일이 저장되는 위치

| 시스템 | 기본 위치 | 빠르게 여는 방법 |
| --- | --- | --- |
| Windows | 사용자 폴더의 `다운로드` | 브라우저에서 **Ctrl + J**를 누릅니다 |
| macOS | 홈 폴더의 `다운로드` | Dock의 다운로드 스택을 클릭합니다 |
| ChromeOS | *파일 → 다운로드* | 실행기의 다운로드 트레이를 클릭합니다 |
| Linux | `~/Downloads` | 브라우저에서 **Ctrl + J**를 누릅니다 |

매번 폴더를 직접 고르고 싶다면 Chrome이나 Edge에서 *설정 → 다운로드*를 열고 **다운로드 전에 각 파일의 저장 위치 확인**을 켜세요. Safari에서는 *설정 → 일반 → 파일 다운로드 위치*에 있습니다.

## 릴스의 음악이 유지되나요?

네. MP4에는 라이선스 곡이든 내레이션이든 원본 사운드든, 인스타그램에서 재생되는 것과 같은 오디오 트랙이 들어 있습니다. 릴스가 인스타그램 음악 라이브러리의 곡을 사용할 때 소리 없는 사본을 저장할 수 있는 휴대폰 앱의 다운로드 버튼과는 다릅니다.

컴퓨터에서 파일에 소리가 없는 것 같다면 다음을 확인하세요.

- 시스템 음량과 미디어 플레이어가 음소거되어 있지 않은지 확인합니다.
- 다른 플레이어에서 파일을 엽니다. **VLC**는 거의 모든 MP4를 재생합니다.
- 원본 릴스가 인스타그램에서 여전히 소리가 나는지 확인합니다.

음악만 필요할 때는 [릴스 오디오 다운로더](/ko/audio)가 같은 링크를 MP3로 저장해 줍니다. [인스타그램 릴스에서 오디오를 추출하는 방법](/ko/blog/extract-audio-from-instagram-reel-mp3)을 참고하세요.

## 다른 방법들과 그 방법이 더 나쁜 이유

**브라우저 확장 프로그램.** instagram.com에 다운로드 버튼을 추가해 주어 편리합니다. 대가는 요구하는 권한입니다. 인스타그램에 로그인한 탭을 포함해, 방문하는 웹사이트의 데이터를 읽고 변경할 수 있게 됩니다. 확장 프로그램은 소유자가 바뀌거나 별다른 공지 없이 스토어에서 내려가기도 합니다. 사용한다면 먼저 권한과 리뷰를 확인하세요.

**화면 녹화.** Windows(Xbox Game Bar, **Win + G**)와 macOS(**⇧ + ⌘ + 5**) 모두 화면을 녹화할 수 있습니다. 화면의 인터페이스까지 함께 담기고, 화질은 디스플레이에 좌우되며, Mac의 기본 녹화 기능은 추가 소프트웨어 없이는 컴퓨터 자체의 소리를 담지 못할 수 있습니다.

**개발자 도구.** 예전 가이드는 브라우저의 검사 도구를 열어 네트워크 탭에서 `.mp4`를 찾으라고 합니다. 지금 인스타그램은 대부분의 동영상을 오디오와 비디오 조각으로 나누어 전송하므로, 대개 소리가 없거나 불완전한 파일을 얻게 됩니다.

**데스크톱 프로그램.** 인스타그램에서 다운로드해 주는 프로그램이 있긴 하지만, 가끔 받는 릴스를 위해 소프트웨어를 설치하는 것은 브라우저 탭 하나보다 위험하고 번거롭습니다.

## 릴스를 휴대폰으로 보내기

MP4가 컴퓨터에 있으면 휴대폰으로 옮기는 것은 금방입니다.

- **Mac에서 iPhone으로:** 파일을 오른쪽 클릭하고 *공유 → AirDrop*을 선택합니다. 바로 사진에 들어갑니다.
- **Windows나 Chromebook에서 Android로:** **Quick Share**를 사용하거나, USB 케이블을 연결해 파일을 휴대폰의 *Download* 또는 *DCIM* 폴더로 드래그합니다.
- **어떤 조합이든:** Google Drive, iCloud Drive, OneDrive에 업로드하거나 나에게 메시지로 보냅니다.

아니면 이 단계에서 컴퓨터를 건너뛰어도 됩니다. 같은 다운로더가 휴대폰 브라우저에서도 작동합니다. 이 가이드의 휴대폰 버전은 [릴스를 음악과 함께 갤러리에 저장하는 방법](/ko/blog/save-instagram-reels-in-gallery-with-music)입니다.

## 데스크톱에서 사진과 여러 장 게시물 저장하기

같은 입력창은 릴스뿐 아니라 게시물 링크(`instagram.com/p/…`)도 받습니다. 사진 한 장은 JPG로 저장되고, 여러 장 게시물은 모든 슬라이드가 나열됩니다. 자세한 내용은 [스크린샷 없이 인스타그램 사진을 저장하는 방법](/ko/blog/save-instagram-photos-without-screenshot)에 있습니다.

## 다운로드되지 않는 것

- **비공개 계정.** 같은 브라우저에서 인스타그램에 로그인해 있어도 달라지지 않습니다. 다운로더는 내 세션을 볼 수 없고 공개 게시물에만 접근할 수 있습니다.
- **삭제된 릴스.** 삭제된 릴스의 링크는 아무것도 반환하지 않습니다.
- **잘못된 링크.** 프로필 주소(`instagram.com/username`)는 릴스가 아닙니다. 릴스 자체를 열어 다시 복사하세요.
