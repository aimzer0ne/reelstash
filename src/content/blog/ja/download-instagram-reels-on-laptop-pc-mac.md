ノートパソコンやデスクトップでは、Instagramにリールを保存する方法がありません。**ダウンロード**機能があるのはスマホアプリだけです。簡単な回避策は、ブラウザからリールのアドレスをコピーし、[Instagram動画ダウンローダー](/ja)に貼り付けてMP4を保存することです。Windows、macOS、Linux、ChromeOSの最新のブラウザならどれでも使え、音楽もファイルに残ります。

## 手順

### 1. リールのリンクをコピーする

**instagram.com**でリールを開きます。リンクを取得する方法は2つあります。

- **アドレスバーから。** アドレスをクリックして選択し、コピーします。リールのリンクは `instagram.com/reel/…` または `instagram.com/reels/…` のような形です。
- **メニューから。** リールの**3点メニュー**をクリックし、**リンクをコピー**を選びます。

リールのフィードをスクロールしていると、リールが切り替わるたびにアドレスバーも更新されます。コピーする前に、目的のリールが再生されていることを確認してください。

### 2. ダウンローダーに貼り付ける

新しいタブで[reelsdl.net](/ja)を開きます。入力欄をクリックして **Ctrl + V**（Windows、Linux、ChromeOS）または **⌘ + V**（Mac）を押し、**Enter**を押します。

### 3. MP4を保存する

数秒でリールのプレビューが表示されます。**動画をダウンロード**をクリックすると、ファイルがダウンロードフォルダに保存されます。

## ファイルの保存先

| OS | 既定の保存先 | すばやく開く方法 |
| --- | --- | --- |
| Windows | ユーザーフォルダ内の `ダウンロード` | ブラウザで **Ctrl + J** を押す |
| macOS | ホームフォルダ内の `ダウンロード` | Dockのダウンロードスタックをクリックする |
| ChromeOS | *ファイル → ダウンロード* | シェルフのダウンロードトレイをクリックする |
| Linux | `~/Downloads` | ブラウザで **Ctrl + J** を押す |

毎回フォルダを選びたい場合は、ChromeやEdgeで*設定 → ダウンロード*を開き、**ダウンロード前に各ファイルの保存場所を確認する**をオンにします。Safariでは*設定 → 一般 → ファイルのダウンロード先*にあります。

## リールの音楽は残りますか？

はい。MP4には、ライセンス楽曲、ナレーション、オリジナル音源のいずれであっても、Instagramで再生されるのと同じ音声トラックが入っています。これは、Instagramのミュージックライブラリの曲を使ったリールを無音で保存することがあるスマホアプリの「ダウンロード」ボタンとは異なる点です。

パソコンでファイルが無音に感じられる場合は次を確認します。

- システムの音量とメディアプレーヤーがミュートになっていないか確認する。
- 別のプレーヤーでファイルを開く。**VLC**はほぼすべてのMP4を再生できます。
- 元のリールがInstagramで今も音付きで再生されるか確認する。

音楽だけが必要なら、[リール音声ダウンローダー](/ja/instagram-audio-downloader)で同じリンクをMP3として保存できます。[Instagramリールから音声を抽出する方法](/ja/blog/extract-audio-from-instagram-reel-mp3)をご覧ください。

## ほかの方法と、それらが劣る理由

**ブラウザ拡張機能。** instagram.comにダウンロードボタンを追加してくれるので便利です。その代わり、アクセスしたウェブサイトのデータの読み取りと変更という権限を求められ、Instagramにログインしているタブも対象になります。拡張機能は運営者が変わったり、予告なくストアから削除されたりすることもあります。使う場合は、先に権限とレビューを確認してください。

**画面収録。** Windows（Xbox Game Bar、**Win + G**）もmacOS（**⇧ + ⌘ + 5**）も画面を録画できます。ただし画面の操作部分まで映り込み、画質はディスプレイに左右され、Macの標準機能は追加ソフトなしではパソコン内部の音を録音できないことがあります。

**デベロッパーツール。** 古い解説では、ブラウザの検証ツールを開いてネットワークタブで `.mp4` を探すよう案内されています。現在のInstagramはほとんどの動画を音声と映像の別々のセグメントで配信しているため、たいていは無音か不完全なファイルになります。

**デスクトップ用ソフト。** Instagramからダウンロードするソフトはありますが、たまにリールを保存するためにソフトをインストールするのは、ブラウザのタブを開くよりリスクも手間も大きくなります。

## リールをスマホに送る

MP4がパソコンに保存できたら、スマホへはすぐに移せます。

- **MacからiPhoneへ:** ファイルを右クリックし、*共有 → AirDrop*を選びます。そのまま「写真」に入ります。
- **WindowsやChromebookからAndroidへ:** **クイック共有**を使うか、USBケーブルをつないでファイルをスマホの*Download*または*DCIM*フォルダにドラッグします。
- **どの組み合わせでも:** Googleドライブ、iCloud Drive、OneDriveにアップロードするか、自分宛てにメッセージで送ります。

この手順ではパソコンを使わない手もあります。同じダウンローダーはスマホのブラウザでも動きます。このガイドのスマホ版は[リールを音楽付きでギャラリーに保存する方法](/ja/blog/save-instagram-reels-in-gallery-with-music)です。

## パソコンで写真や複数枚投稿を保存する

同じ入力欄は、リールだけでなく投稿のリンク（`instagram.com/p/…`）にも対応しています。写真1枚はJPGで保存され、複数枚投稿はすべてのスライドが一覧表示されます。詳しくは[スクショなしでInstagramの写真を保存する方法](/ja/blog/save-instagram-photos-without-screenshot)をご覧ください。

## ダウンロードできないもの

- **非公開アカウント。** 同じブラウザでInstagramにログインしていても関係ありません。ダウンローダーはあなたのセッションを見ることはなく、公開投稿にしかアクセスできません。
- **削除されたリール。** 削除されたリールのリンクは何も返しません。
- **間違ったリンク。** プロフィールのアドレス（`instagram.com/username`）はリールではありません。リール自体を開いてコピーし直してください。
