Les Reels enregistrés avec le bouton **Télécharger** d'Instagram comportent un logo Instagram flottant et le nom d'utilisateur du créateur par-dessus la vidéo. Pour obtenir une copie propre, téléchargez plutôt le Reel **par son lien** : copiez le lien, collez-le dans le [téléchargeur de Reels Instagram](/fr) et enregistrez le MP4. Ce fichier est la vidéo telle qu'elle a été envoyée, sans rien ajouté par-dessus.

## Ce qu'est le filigrane d'Instagram

Lorsque vous touchez *Partager → Télécharger* sur un Reel public, Instagram ne vous remet pas le fichier d'origine. Il crée une nouvelle copie et y ajoute :

- le logo Instagram,
- le **@nom d'utilisateur** du créateur,
- le nom de l'audio.

Les <a href="https://help.instagram.com/iphone-app/520831036611383" target="_blank" rel="noopener noreferrer">pages d'aide d'Instagram</a> présentent cela comme la norme pour tout Reel téléchargé. Il n'existe aucun interrupteur pour le désactiver, ni pour les spectateurs ni pour le créateur.

Le filigrane ne se trouve pas dans le Reel lui-même. La vidéo lue dans votre fil est propre, et la surimpression n'est ajoutée qu'au moment du téléchargement. C'est pourquoi un téléchargeur par lien peut renvoyer une copie sans filigrane : il récupère le même fichier propre que celui que votre téléphone lit déjà.

### 1. Télécharger le Reel par lien

C'est la méthode pour les Reels d'autres comptes publics, et pour vos propres Reels une fois publiés.

1. Ouvrez le Reel dans Instagram, touchez les **trois points** ou la **flèche de partage** et choisissez **Copier le lien**.
2. Allez sur [reelsdl.net](/fr) dans votre navigateur.
3. Touchez **Coller**, ou collez vous-même le lien dans le champ. Le Reel se charge tout seul.
4. Touchez **Télécharger la vidéo** sur l'aperçu.

Cela fonctionne de la même façon dans Safari sur iPhone, Chrome sur Android et n'importe quel navigateur sur ordinateur. Aucune application à installer, aucune connexion à Instagram. Sur iPhone, le fichier va d'abord dans l'app Fichiers ; le guide pour [enregistrer des Reels dans la galerie](/fr/blog/save-instagram-reels-in-gallery-with-music) explique comment le déplacer vers Photos.

### 2. Conserver l'original de votre propre Reel

Si le Reel est le vôtre, la copie la plus propre est celle que vous n'avez jamais confiée à Instagram.

- **Montez en dehors d'Instagram.** Créez le Reel dans un éditeur vidéo, exportez-le dans votre pellicule, puis envoyez ce fichier. Votre copie maîtresse n'a pas de filigrane et n'est pas passée par la compression d'Instagram.
- **Enregistrez avant de publier.** Dans l'éditeur de Reels, la flèche de téléchargement enregistre le clip sans filigrane. Sachez qu'un titre de la bibliothèque musicale d'Instagram n'est pas inclus dans cette copie.
- **Déjà publié ?** Si votre compte est public, traitez votre Reel comme n'importe quel autre : copiez son lien et téléchargez-le. La musique est ainsi conservée.

### 3. Enregistrer l'écran et recadrer

L'enregistrement d'écran capture tout ce qui s'affiche, y compris le bouton J'aime, la légende et le nom d'utilisateur. Vous devez ensuite recadrer l'image pour les masquer, ce qui supprime une partie de l'image et réduit la résolution. Gardez cette méthode en dernier recours, pour un Reel impossible à enregistrer autrement.

## Ce qu'un téléchargeur ne peut pas retirer

- **Les filigranes intégrés par le créateur.** Un logo, un pseudo écrit dans un coin ou le filigrane d'une autre application présent dans la vidéo avant l'envoi font partie de l'image.
- **Les textes et stickers.** Le texte, les GIF et les stickers ajoutés dans l'éditeur de Reels sont fusionnés à la vidéo.
- **Les Reels privés.** Ils ne peuvent tout simplement pas être récupérés par lien.

## Avant de republier un Reel propre

Le filigrane existe pour que le crédit reste attaché au créateur. Le retirer ne lui enlève pas ses droits sur la vidéo.

- **Demandez d'abord.** Un court message au créateur suffit généralement.
- **Créditez dans la légende.** Identifiez le compte d'origine à un endroit visible.
- **N'attendez pas de portée des republications.** Instagram a indiqué favoriser les contenus originaux dans les recommandations et remplacer les republications par l'original lorsqu'il le trouve. Un Reel d'autrui remis en ligne a peu de chances d'aller loin.

Pour vos propres contenus, c'est plus simple : un fichier propre est exactement ce qu'il vous faut pour publier le même Reel sur TikTok, YouTube Shorts ou Facebook, où le logo d'une autre plateforme peut nuire au traitement de la vidéo.
